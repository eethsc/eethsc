### 👨‍💻 About Me

사용자 중심의 실용적인 웹 서비스부터 지능형 AI 에이전트, 딥테크 자동화 파이프라인까지 **문제를 명확히 정의하고 실제로 작동하는 엔드투엔드 프로덕트**를 만드는 풀스택 소프트웨어 엔지니어입니다.

- 🌐 **Full-Stack & Platforms:** 실생활의 문제를 해결하는 반응형 웹 플랫폼, 시니어 헬스케어 및 로컬 서비스 아키텍처를 설계하고 구현합니다.
- 🤖 **AI Agents & Automation:** 반복적인 비즈니스·개발 워크플로우를 자동화하는 지능형 에이전트 시스템을 구축합니다.
- 💡 **Engineering Approach:** 
  - 사용자 경험(UX)과 견고한 백엔드 시스템 설계의 균형을 중요하게 생각합니다.
  - 컨테이너화(`Docker`)와 클라우드 배포를 고려한 지속 가능하고 확장성 있는 코드를 지향합니다.
  - 웹 서비스뿐만 아니라 알고리즘, 데이터 파이프라인, 시스템 레벨의 복잡한 로직도 집요하게 해결합니다.
