### 👨‍💻 About Me

하드웨어·프로세서 레벨의 기본 물리 원리부터 대규모 데이터를 다루는 풀스택 웹 플랫폼, 폐루프(Closed-Loop) 자율 AI 에이전트까지 **컴퓨터 시스템의 전 계층을 관통하며 실질적인 가치를 창출하는 소프트웨어 아키텍트**입니다.

- 🌐 **Full-Stack & Cloud Databases:** 실사용자를 위한 반응형 PWA, Supabase(PostgreSQL + RLS 보안 정책) 기반의 멀티 테넌트 데이터베이스, Vite/React 플랫폼을 설계 및 운영합니다.
- 🤖 **Agentic Pipelines & Deep Search:** 4대 골든 스택(Tavily, Exa, Firecrawl, Scrape.do)과 GitHub Actions CI/CD를 결합하여 수천 건의 이기종 데이터를 매일 자동 전수조사·정제하는 무중단 에이전틱 파이프라인을 구축합니다.
- ⚙️ **Low-Level & Deep Tech Synthesis:** 프로세서 아키텍처(FPGA/Vivado), 혼합신호 회로(SAR-ADC), 데이터시트 기반의 순수 물리 자율 합성 및 4단계 인과 검증 프레임워크를 직접 연구·구현합니다.
