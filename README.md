### 👨‍💻 About Me

복잡한 물리 계층의 회로부터 고도화된 자율 AI 에이전트 시스템까지, **문제를 끝까지 파고들어 실제로 동작하는 구조**를 만드는 엔지니어입니다.

- 🔭 **What I Do:** 소프트웨어와 하드웨어의 경계를 허물고, 복잡한 엔지니어링 문제를 자율화·최적화하는 지능형 시스템을 구축합니다.
- ⚙️ **Engineering Principles:**
  - **First-Principles Thinking:** 겉핥기식 구현보다 기본 물리 원리와 코어 아키텍처부터 단단하게 설계합니다.
  - **Pragmatic Automation:** 비효율적인 반복 검증과 개발 파이프라인을 자율 에이전트와 도구로 혁신합니다.
- 🌱 **Interests:** 자율 에이전트 오케스트레이션, 반도체/혼합신호 설계 자동화(EDA), 대규모 시스템 설계.
- 💬 **Ask Me About:** 하드웨어-소프트웨어 융합 시스템, AI 에이전트 구조, 회로 설계 및 자동화.
